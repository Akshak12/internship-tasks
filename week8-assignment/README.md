# E-Commerce Order Analytics System

A Python + SQLite data pipeline that generates messy e-commerce data, cleans it, loads it into a database, and runs SQL analytics and business reports on it.

---

## What it does

1. **Generates** raw order data with intentional issues — duplicates, missing IDs, negative prices, future dates, invalid discounts.
2. **Cleans** the data using Pandas — removes bad records, masks PII, fixes referential integrity.
3. **Loads** the cleaned data into a local SQLite database (`freshmart.db`).
4. **Analyzes** it using SQL — aggregations, window functions, cohort retention, RFM segmentation.
5. **Reports** via a CLI tool that prints business summaries and saves charts.
6. **Tests** 4 edge cases to confirm the cleaning logic works as expected.

## How to Run

**1. Install dependencies**
```bash
pip install pandas faker tabulate matplotlib
```

**2. Generate raw data**
```bash
python scripts/generate_data.py
```

**3. Clean and load into database**
```bash
python scripts/clean_data.py
```

**4. Run edge case tests**
```bash
python testedge_cases.py
```

**5. Generate reports**
```bash
python scripts/report_cli.py --report revenue --plot
python scripts/report_cli.py --report top_products --plot
python scripts/report_cli.py --report retention --plot
python scripts/report_cli.py --report customers --plot
python scripts/report_cli.py --report delivery --plot
```

## Edge Cases Tested

| # | Question | Behaviour |
|---|---|---|
| 1 | What if `order_items` has an `order_id` not in `orders`? | That item is dropped (referential integrity check) |
| 2 | What if `discount` is greater than 100? | Discount is reset to 0 |
| 3 | What if `quantity` is 0? | That item is dropped (`qty > 0` filter) |
| 4 | What if `order_date` is in the future? | That order is dropped |
