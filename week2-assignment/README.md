**Objective**
Analyze sales data using SQL with filtering, aggregation, and business queries.

**Dataset**

- **Tool Used:** MySQL Workbench

| Step | Description |

| 4 | Used GROUP BY for aggregations (sales, quantity, averages) |
| 5 | Sorted and limited results (top products, top categories) |
| 6 | Solved business use cases (monthly trends, top customers, duplicates) |
| 7 | Validated data quality (null checks, zero sales, row count) |

**Key Findings**
- West region leads in total sales across all four regions
- Technology is the most profitable category by a large margin
- Furniture has surprisingly weak profit despite high sales value
- Sales spike every Q4 — strong seasonal pattern across all years
- Dataset is clean — no null values or zero-sales records found
